A block element starts a new line and can be sized using the height and width properties.

an inline element does not start a new line and cannot be sized using the height and width properties.

an inline-block element does not start a new line but can be sized using the height and width properties.

what is the default position value? Static

how will rule set with position relative and top at 10px affect the element? It will move the element 10px down from its default position.

what does the z index control? how far back or forward overlapping elements appear on a page.

the z index will be ignored if an elements is set to which of the following position values? static

which of the following positioning values will remove an element from the flow of the html document? fixed

How will rule set position fixed and top 0px affect the element? remove the element from the flow of the document and keep it in the same position within the browser window, even if the user scrolls.

which of the following css properties can be used to set an elements behavior to inline, inline-block, or block? display

Which of the following values will position an element in relation to the nearest non static element? absolute
